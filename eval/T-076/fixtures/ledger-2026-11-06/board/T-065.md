# T-065 · Spec: khôi phục ảnh vendor từ Wayback Machine khi marry.vn chết

## Brief

**Mục tiêu:** Ảnh vendor mà marry.vn không còn trả được lấy lại từ bản lưu của Internet Archive (web.archive.org) và đưa lên Cloudflare Pages theo quy trình T-051/T-064

**Bối cảnh:** Capu đồng ý 2026-11-05 sau khi marry.vn trả 522 nhiều ngày (lịch kiểm marry.vn). ADR-021 (phương án A, tự host) vẫn áp dụng; nguồn bản lưu không đổi chủ sở hữu ảnh. Công cụ: tohong-back scripts/vendor-images/vendor-images.mjs (mirror, dừng sớm mã 4, fail_runs), workflow Mirror vendor images, bất biến planner/vendor/images inv-001..005. Phiên cloud bị chặn archive.org (403) → phần gọi Wayback chạy trên GitHub Actions; eval offline bằng server giả mô phỏng API availability/CDX + id_ raw. Đề xuất: khi nguồn gốc lỗi thì hỏi Wayback bản lưu gần nhất (snapshot gốc, hậu tố id_), tôn trọng giới hạn tốc độ của archive.org (không quá N request/giây), manifest ghi nguồn (source=wayback, timestamp). Không liên hệ vendor, không chi tiền, không đặt secret.

**Bậc lưới lọc:** C — Capu duyệt

**Vùng (bất biến áp dụng):** planner/vendor/images

### Tiêu chí chấp nhận

1. 1. URL gốc lỗi mà Wayback có bản lưu → tải từ Wayback, chuyển WebP, entry ok kèm nguồn; 2. Không có bản lưu → giữ failed như cũ; 3. Giới hạn tốc độ tới archive.org; 4. Bất biến inv-001..005 xanh; dừng sớm vẫn đúng; 5. Workflow có tùy chọn bật nguồn Wayback; README cập nhật; 6. npm test xanh

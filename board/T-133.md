# T-133 · Workflow dữ liệu tohong tự sinh lại enrich-report.json trong cùng PR dữ liệu

## Brief

**Mục tiêu:** Mọi PR dữ liệu do workflow tohong mở (enrich-vendors, enrich-venue, refresh-vendor-photos, resolve-overrides, apply-review-rule) chứa enrich-report.json sinh lại từ dữ liệu cùng commit, để báo cáo admin không cũ như sau #83/#86

**Bối cảnh:** ADR-068 mục 3; adversary T-132: bất biến chờ merge eval/T-132/bat-bien-cho-merge/inv-003-bao-cao-enrich-commit-bang-sinh-lai.py (xanh trên tohong#89, đỏ trên main cũ) sẽ đỏ ở mọi PR dữ liệu sau này nếu workflow không sinh lại. Hiện #84 chỉ ghi hướng dẫn trong README. Lưu ý thêm: file nhúng ở tohong-back (lib/vendorEnrichReport.generated.js) cũng phải sinh lại — đề xuất cách (cùng bước tạo PR pool, tools/regen-pool-styles.sh hoặc lệnh riêng). Eval phải chạy nguyên văn bước workflow (bài học T-118/T-119/T-127), giữ INV-023/024/030/031.

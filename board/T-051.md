# T-051 · Spec: tự host ảnh vendor trên Cloudflare Pages thay hotlink marry.vn

## Brief

**Mục tiêu:** Ảnh vendor trong app được phục vụ từ Cloudflare Pages của Tơ Hồng thay vì hotlink www.marry.vn

**Bối cảnh:** Capu quyết 2026-11-03 (ADR-021): phương án A (tự host toàn bộ ngay, sau xin phép/thay ảnh vendor) + Cloudflare Pages. Hiện trạng: tohong-back/lib/vendorPool.generated.js có 2.810 lượt ảnh, 2.465 URL duy nhất, tất cả www.marry.vn, ~968 vendor; scraper ở phungrk/tohong tools/scraper/. Phiên cloud bị chặn marry.vn (403) → tải ảnh phải chạy ở GitHub Actions hoặc máy Capu. Đề xuất: chuyển WebP ~800px; đường dẫn ổn định theo vendor id + hash; giữ link cũ nếu tải lỗi; Capu tự tạo project Pages + token (không đặt secret thay Capu). Không chi tiền, không liên hệ vendor. Repo đích ảnh: chọn trong spec (repo mới hay thư mục trong phungrk/tohong).

**Bậc lưới lọc:** C — Capu duyệt

**Vùng (bất biến áp dụng):** planner/vendor/images

### Tiêu chí chấp nhận

1. 1. Mọi ảnh vendor trong pool trỏ tới domain Pages (trừ ảnh tải lỗi giữ link cũ, có đếm); 2. Ảnh WebP, rộng ≤ 800px, đúng ảnh gốc; 3. Quy trình tải/chuyển/deploy chạy lại được (idempotent), có hướng dẫn từng bước cho phần Capu làm; 4. App hiện ảnh đúng, có ảnh mặc định khi lỗi; 5. Không secret trong repo; test back xanh

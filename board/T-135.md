# T-135 · Gộp resolve → dữ liệu → pool thành một workflow tự chạy sau khi Capu merge PR duyệt tay; ra một PR cuối

## Brief

**Mục tiêu:** Sau khi Capu merge PR manual_overrides (apply-admin-reviews), một workflow tự chạy resolve-overrides (Google, trong trần), sinh lại enrich-report, tạo lại pool + báo cáo nhúng back, chạy bất biến, mở MỘT PR cuối (hoặc một cặp PR tohong + back liên kết) để Capu merge — Capu chỉ còn 2 lần merge mỗi lô

**Bối cảnh:** Capu đồng ý 2026-11-13 ('đồng ý gộp bước 2–4'). Hiện mỗi lô: merge PR duyệt tay → bấm resolve-overrides.yml → merge PR dữ liệu → Chief of Staff tạo PR pool tohong-back bằng regen-pool-styles.sh + generate-vendor-enrich-report.js → merge. Pool nằm ở repo khác (tohong-back), nên cần token ghi chéo repo (secret Capu đặt) hoặc workflow ở back kéo dữ liệu tohong — đề xuất cách an toàn nhất, không đặt secret thay Capu. Giữ: trần 0/tháng (ADR-049), sổ đăng ký lần chạy (check_runs), INV-023/024/030/031, inv-005/006 (planner), bất biến pool (INV-013/014/021/022/029), vendor-enrich inv-001..004. Gộp với T-133 (workflow tự sinh lại enrich-report.json) — đọc board/T-133.md, có thể gom thành một spec. Tự kích hoạt khi merge thì xét: Google tốn tiền nên có cần Capu bấm không (đề xuất, nêu lý do).

# T-140 · Chat AI ghép vendor bằng computeMatches trong Worker (thêm nới điều kiện + MMR), bỏ matcher Cloud Run

## Brief

**Mục tiêu:** Chat gợi ý vendor từ pool hiện hành bằng bộ ghép JS trong Worker, chất lượng không kém matcher Python; không còn phụ thuộc Cloud Run/GCS

**Bối cảnh:** ADR-077 (Capu chọn B). Cloud Run matcher-service đang 'Service is disabled' nên chat hiện không có ứng viên. Đường hiện tại: lib/contextBuilder.js → callMatcher (lib/matcherAdapter.js) → poolFilter → matchFormatter. Bộ JS: lib/vendorMatcher.js computeMatches (tab Vendor, api/vendors.js). Python: matcher/matcher.py (lọc cứng → _relax_and_retry → score_and_rank → apply_boosts → apply_mmr_diversity). Giữ từ T-136/T-138: poolFilter, prompt A9, khối khoảng trống, inv-033/034 (inv-033 sẽ lỗi thời khi gỡ matcher-data → đề xuất xử lý qua Chief of Staff + decisions/).

**Bậc lưới lọc:** B — Chief of Staff merge sau accept

**Vùng (bất biến áp dụng):** planner/vendor/images

### Tiêu chí chấp nhận

1. Spec + eval tầng 1: chat dùng computeMatches; nới điều kiện + MMR có eval so với Python trên cùng hồ sơ; tab Vendor không đổi hành vi ngoài ý muốn (hoặc nói rõ đổi gì); phần gỡ Cloud Run tách thành bước/PR sau, có lệnh cho Capu

# T-094 · Làm chặt quy tắc tên bất biến trong drawer: không lấy dòng code hay đường dẫn máy

## Brief

**Mục tiêu:** Tên bất biến xuất công khai luôn là mô tả, không bao giờ là dòng code hay đường dẫn máy, kể cả khi file bất biến viết lạ

**Bối cảnh:** Adversary T-093: quy tắc tên spec T-092 bước 1b (dòng đầu tiên ≥ 50 ký tự trong 12 dòng đầu) có thể lấy dòng code (vd r = subprocess.run(...)) hoặc dòng có /home/... vào bản --public. Bể hiện sạch nhờ quy ước ADR-032. Cũng: file bất biến ở gốc eval/invariants cho area '.' và url có '/./'.

**Bậc lưới lọc:** A — tự merge khi eval xanh

**Vùng (bất biến áp dụng):** hq/dashboard/model

### Tiêu chí chấp nhận

1. 1) name không bao giờ là dòng code (bắt đầu bằng ký tự/từ khoá code) hay chứa đường dẫn máy (/home/, /root/, /tmp/) hoặc 'handoffs/'; rơi về bước kế (INV-nnn ·, slug, tên file). 2) file ở gốc eval/invariants có area và url hợp lệ. 3) tên của toàn bể thật không đổi so với hiện tại (trừ ca được sửa có chủ ý). 4) INV-009, INV-017 xanh.

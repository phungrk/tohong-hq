# T-013: gate lint của tohong-front tính là "không thêm lỗi so với main"

**Bối cảnh:** tiêu chí 9 của T-013 đòi `npm run lint` của `tohong-front`. Chief of Staff tự chạy `npx eslint .` trên `origin/main` sạch (`ed18f26`): 32 error, 3 warning có sẵn. Nhánh PR phungrk/tohong-front#48 cho đúng 32 error, 3 warning, không lệch dòng nào; file mới 0 lỗi; không tắt rule.

**Quyết định:** với T-013, tiêu chí 9 phần lint đạt khi PR không thêm lỗi lint nào so với `main` và file mới sạch lint. Không sửa 32 lỗi cũ trong PR này (nhiều file ngoài phạm vi, có thể đụng `AppChat.jsx` được bảo vệ). Ghi nợ FRONT-001 vào `docs/tech-debt.md` của `tohong`.

**Lý do:** sửa nợ lint có sẵn trong PR tính năng làm phình diff, tăng rủi ro chạm thành phần được bảo vệ (constitution V), và lệch phạm vi brief.

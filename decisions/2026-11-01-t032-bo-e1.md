# T-032: bỏ ngoại lệ E1 — khối Agent code sáng khi có việc chờ

**Bối cảnh:** Spec Gate trả T-032 (`handoffs/T-032-D1.md`): ngoại lệ E1 để khối Agent code tối khi hiện "1 chờ" (việc `engineering` `new`) — đúng kiểu lỗi Capu vừa báo ở khối Ý định, và lý do E1 tự mâu thuẫn với quy tắc cho việc `product` `new`.

**Quyết định:** bỏ E1. Khối `nd_exec` sáng màu code khi có ít nhất một việc `engineering` ở `new`, `doing` hoặc `rework` (số lớn hoặc số "chờ" > 0); tắt khi cả hai bằng 0. Con số hiển thị giữ nguyên (không gộp). ADR-012 mục 1 sửa theo: ngoại lệ còn E2–E6.

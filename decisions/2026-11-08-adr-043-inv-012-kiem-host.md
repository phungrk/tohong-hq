# INV-012 vendor/images kiểm host URL như trình duyệt (siết, không nới)

**Bối cảnh:** Code Gate T-104 lần 2 (adv-05) tìm ra lỗ. Bốn URL sau đều được trình duyệt đọc thành host `places.googleapis.com`:
- `places%2Egoogleapis.com`
- `places%2egoogleapis%2ecom`
- `places。googleapis.com`
- `places．googleapis.com`

Bộ lọc của generator, và cả INV-012 bản đầu, so chuỗi thô nên để lọt cả bốn.

**Quyết định:**
1. INV-012 giữ bốn mẫu so chuỗi cũ và thêm bước tách URL như trình duyệt:
   - Giải mã escape, giải mã `%`, chuẩn hoá NFKC, dấu chấm Unicode và chữ hoa/thường.
   - Bỏ userinfo, cổng và dấu chấm cuối.
   - FAIL khi host là `places.googleapis.com` hoặc `maps.googleapis.com`, kể cả tên miền con.
   - FAIL khi query có tham số `key`, kể cả viết dạng mã hoá.
2. Đây là siết thêm. Kết quả kiểm:
   - PASS trên pool thật (tohong-back d3dfa18, 132 ảnh lh3).
   - FAIL trên 4 dạng lách và 36 fixture hỏng.
   - Ba nhóm đối chứng đúng vẫn PASS.
3. INV-013 không đổi.

**Hệ quả:** mọi việc chạm `planner/vendor/images` chạy INV-012 mới ở tầng 2. Bất biến chỉ đỏ khi pool thật chứa URL bị cấm.
